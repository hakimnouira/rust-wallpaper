3-Step Quick Install

One-Click Windows Setup

  1. Download RustWallpaper-0.1.0-Setup.exe
    Click the download button above to grab the all-in-one Windows x64 installer.
  2. Run the setup wizard
    Double-click RustWallpaper-0.1.0-Setup.exe, choose your install folder, and complete installation (includes MPV, FFmpeg, and browser extension registration).
  3. Launch from Start Menu
    Open Rust Wallpaper from the Start Menu or Desktop shortcut, import videos or browse free loops, and enable the browser extension under Settings.

Optional Setup & Details

Portable Mode (No Installer)

Download RustWallpaper-0.1.0-windows-x64.zip from the button above, extract it anywhere, and run RustWallpaper.exe directly without modifying Start Menu shortcuts.

Browser Companion Extension (Chrome, Edge, Brave)

Capture videos directly from Pinterest, TikTok, Instagram, Reddit, YouTube, and Wallhaven over the local loopback bridge (127.0.0.1:24242).

  1. Open RustWallpaper → Settings → Browser Companion Integration and click Auto-Configure Shortcuts or Launch Browser with Extension.
  2. For manual Developer Mode loading, open chrome://extensions (or edge://extensions), turn on Developer mode, and click Load unpacked on %LOCALAPPDATA%\RustWallpaper\extension.
Build from Source (Developers)

Requires Rust 1.78+, Visual Studio C++ Build Tools (or MinGW-w64), and mpv.exe / ffmpeg.exe in %USERPROFILE%\.mpv.

git clone https://github.com/hakimnouira/rust-wallpaper.git
cd rust-wallpaper
powershell -ExecutionPolicy Bypass -File .\scripts\build-production.ps1
Keyboard Shortcuts, Data Paths & Troubleshooting
  • Global Hotkeys: Alt + W (Next Wallpaper), Alt + M (Toggle Mute), Esc (Hide to tray), F5 (Refresh).
  • Data & Logs: Stored in %LOCALAPPDATA%\RustWallpaper\ (library.db, thumbnails, and logs\daemon.YYYY-MM-DD.log).
  • Paused during games? Fullscreen pause automation frees 100% of GPU/CPU resources when games are focused; adjust this in Settings.
