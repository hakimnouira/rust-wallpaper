Install RustWallpaper

Choose the Windows installer for automatic Start Menu and browser extension setup, run in portable mode with zero registry changes, or compile directly from source.

System Requirements

Operating System

Windows 10 or Windows 11 (x64).

Graphics & Decoding

GPU supporting DXVA2 / D3D11VA hardware video decoding and OpenGL for the control panel.

Optional Integrations

Chromium browser (Chrome, Edge, or Brave) for the companion extension; Steam for Workshop sync.

Installation Methods

1. Windows Installer (Recommended)

  1. Download RustWallpaper-0.1.0-windows-x64.zip from GitHub Releases.
  2. Extract the archive and run RustWallpaper-Setup.exe.
  3. Select an install folder (defaults to %LOCALAPPDATA%\RustWallpaper) and finish setup.
  4. Launch Rust Wallpaper from the Start Menu or Desktop shortcut.

2. Portable Mode

  1. Download and extract RustWallpaper-0.1.0-windows-x64.zip anywhere.
  2. Run RustWallpaper.exe directly without modifying system-wide shortcuts or install paths.

3. Build from Source

Requires Rust 1.78+, Visual Studio C++ Build Tools (or MinGW-w64), and mpv.exe / mpv-2.dll in %USERPROFILE%\.mpv or beside binaries.

git clone https://github.com/hakimnouira/rust-wallpaper.git
cd rust-wallpaper
cargo build --release --workspace

Or build the full distribution package (binaries, MPV bundle, extension CRX, and setup wizard):

powershell -ExecutionPolicy Bypass -File .\scripts\build-production.ps1

Browser Companion Extension (Chrome, Edge, Brave)

Capture videos from Pinterest, TikTok, Instagram, Reddit, YouTube, and Wallhaven in one click. Extension ID: gemjknbkapmdcopknokbikcneknbpoij • Loopback API: 127.0.0.1:24242.

  1. Open RustWallpaper and go to Settings → Browser Companion Integration.
  2. Click Enable Extension (or Auto-Configure Shortcuts / Launch Browser with Extension).
  3. If loading manually in Developer Mode, open chrome://extensions (or edge://extensions), enable Developer mode, and click Load unpacked on %LOCALAPPDATA%\RustWallpaper\extension (or extensions\chrome in the repo).
  4. Restart your browser if updating from an older CRX package so version 1.0.1 loads cleanly.

Troubleshooting & FAQ

The browser extension says unauthorized or monitor not found

Ensure both wallpaper-daemon and the browser extension are updated to the matching build (extension v1.0.1), restart the daemon, and reload the extension in your browser.

Wallpaper freezes or pauses when I launch a game

This is intentional fullscreen automation to free 100% of GPU and CPU resources for games. You can adjust fullscreen pause behavior in Settings.

Where are logs stored if something fails to play?

Daily diagnostic logs are written to %LOCALAPPDATA%\RustWallpaper\logs\daemon.YYYY-MM-DD.log.
