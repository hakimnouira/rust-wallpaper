Install RustWallpaper

Use the guided Windows installer for Start Menu shortcuts and automatic browser extension registration, run in portable mode with zero registry writes, or compile from source.

Choose Your Installation Method

Recommended

Option 1: Windows Installer

  1. Download RustWallpaper-0.1.0-windows-x64.zip from GitHub Releases.
  2. Extract the archive and run RustWallpaper-Setup.exe.
  3. Choose an install directory (defaults to %LOCALAPPDATA%\RustWallpaper) and complete the wizard.
  4. Launch Rust Wallpaper from the Start Menu or Desktop shortcut.
Zero Install

Option 2: Portable Mode

  1. Download and extract RustWallpaper-0.1.0-windows-x64.zip into any folder.
  2. Run RustWallpaper.exe directly—no Start Menu entries or system-wide changes required.
  3. Closing the window keeps the engine running cleanly in your Windows system tray.
Developers

Option 3: Build from Source

Requires Rust 1.78+, Visual Studio C++ Build Tools (or MinGW-w64), and mpv.exe / mpv-2.dll placed in %USERPROFILE%\.mpv or beside the compiled binaries. 

git clone https://github.com/hakimnouira/rust-wallpaper.git
cd rust-wallpaper
cargo build --release --workspace

To compile release binaries, bundle MPV, package chrome.crx, and generate RustWallpaper-Setup.exe in dist\:

powershell -ExecutionPolicy Bypass -File .\scripts\build-production.ps1

Automatic Setup inside RustWallpaper

  1. Open RustWallpaper and navigate to Settings → Browser Companion Integration.
  2. Ensure Integrate with web browsers is enabled, or click Auto-Configure Shortcuts / Launch Browser with Extension.
  3. Restart your browser so the signed v1.0.1 extension activates.

Manual Developer Mode Load

  1. Open chrome://extensions (or edge://extensions / brave://extensions).
  2. Toggle Developer mode on in the top-right corner.
  3. Click Load unpacked and select %LOCALAPPDATA%\RustWallpaper\extension (or extensions\chrome from the repository).
  4. Open the extension popup and choose your target monitor (e.g. All Monitors or \\.\DISPLAY1).

Troubleshooting & FAQ

The browser extension says unauthorized or monitor not found

Make sure both wallpaper-daemon and the browser extension are updated to the matching release (extension v1.0.1), restart the daemon, and reload the extension in your browser.

Wallpaper pauses automatically when I open a game

Fullscreen pause automation frees 100% of GPU and CPU power while games or fullscreen apps are focused. You can customize this behavior under Settings → Playback automation.

Where can I inspect diagnostic logs?

Daily daemon logs are saved in %LOCALAPPDATA%\RustWallpaper\logs\daemon.YYYY-MM-DD.log, and you can open that folder directly from the Settings tab.
